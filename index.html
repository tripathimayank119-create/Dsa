Experiment 1

Aim

Perform insertion, deletion, traversal and search operations on 1D arrays.

Part A (Question)

Write a Java program to manage the daily temperature readings of a city using a 1D array. Implement insertion at a given position, deletion of a reading, linear search for a specific temperature, and traversal of all readings.

Part B (Output / Analysis)

Display the array before and after each operation and analyze the time complexity of insertion, deletion, search and traversal.

Java Code 

import java.util.*;
public class Exp1 {
static int[] a = new int[10];
static int n = 5;
static void show(String s) { System.out.println(s + Arrays.toString(Arrays.copyOf(a, n))); }
public static void main(String[] args) {
int[] t = {30, 32, 35, 31, 29};
System.arraycopy(t, 0, a, 0, 5);
show("Original
: ");
int pos = 2;
// insert 40 at index 2
for (int i = n; i > pos; i--) a[i] = a[i - 1];
a[pos] = 40; n++;
show("After insert : ");
pos = 1;
// delete index 1
for (int i = pos; i < n - 1; i++) a[i] = a[i + 1];
n--;
show("After delete : ");
int idx = -1;
for (int i = 0; i < n; i++) if (a[i] == 35) { idx = i; break; }
System.out.println("Search 35 at index: " + idx);
System.out.print("Traversal: ");
for (int i = 0; i < n; i++) System.out.print(a[i] + " ");
}
}

After insert : [30, 32, 40, 35, 31, 29]

Traversal: 30 40 35 31 29

Analysis

Insertion O(n), Deletion O(n) (elements shift), Linear Search O(n), Traversal O(n). Access by index is O(1).

Experiment 3

Aim

Implement Stack operations using arrays.

Part A (Question)

Design a Java program to simulate the back-button history of a web browser using an array-based Stack. Implement push, pop, peek, isEmpty and isFull operations and handle stack overflow and underflow conditions.

Part B (Output / Analysis)

Display the stack contents after each operation and explain the LIFO principle along with overflow and underflow situations.

Java Code 

public class Exp3 {
static String[] st = new String[3];
static int top = -1;
static boolean isEmpty() { return top == -1; }
static boolean isFull() { return top == st.length - 1; }
static void push(String p) {
if (isFull()) System.out.println("Overflow! Cannot visit " + p);
else st[++top] = p;
}
static String pop() {
if (isEmpty()) { System.out.println("Underflow! No history"); return null; }
return st[top--];
}
static String peek() { return isEmpty() ? null : st[top]; }
static void show() {
System.out.print("Stack: ");
for (int i = 0; i <= top; i++) System.out.print(st[i] + " ");
System.out.println();
}
public static void main(String[] args) {
push("google.com"); show();
push("youtube.com"); show();
push("gmail.com"); show();
push("github.com");
// overflow
System.out.println("Current page: " + peek());
System.out.println("Back from: " + pop()); show();
pop(); pop(); pop();
// last pop -> underflow
System.out.println("isEmpty: " + isEmpty());
}
}

Output

Stack: google.com
Stack: google.com youtube.com
Stack: google.com youtube.com gmail.com
Overflow! Cannot visit github.com
Current page: gmail.com
Back from: gmail.com
Stack: google.com youtube.com
Underflow! No history
isEmpty: true

Analysis

LIFO: last pushed = first popped. Overflow = push on full stack; Underflow = pop on empty stack.

Experiment 4

Aim

Implement Queue operations using arrays.

Part A (Question)

Develop a Java program to simulate a printer job queue using an array-based Queue. Implement enqueue, dequeue, front, isEmpty and isFull operations for incoming print jobs.

Part B (Output / Analysis)

Display the queue status before and after each operation, explain the FIFO principle, and discuss the wasted-space limitation of a linear queue.

Java Code 

public class Exp4 {
static String[] q = new String[3];
static int front = 0, rear = -1;
static boolean isEmpty() { return rear < front; }
static boolean isFull() { return rear == q.length - 1; }
static void enqueue(String j) {
if (isFull()) System.out.println("Queue Full! " + j + " rejected");
else q[++rear] = j;
}
static String dequeue() {
if (isEmpty()) { System.out.println("Queue Empty!"); return null; }
return q[front++];
}
static void show() {
System.out.print("Queue: ");
for (int i = front; i <= rear; i++) System.out.print(q[i] + " ");
System.out.println();
}
public static void main(String[] args) {
enqueue("Job1"); enqueue("Job2"); enqueue("Job3"); show();
enqueue("Job4");
// full
System.out.println("Front: " + q[front]);
System.out.println("Printing: " + dequeue()); show();
enqueue("Job5");
// still full: freed slot at index 0 is wasted
dequeue(); dequeue(); dequeue();
// last one -> empty
}
}

Output

Queue: Job1 Job2 Job3
Queue Full! Job4 rejected
Front: Job1
Printing: Job1
Queue: Job2 Job3
Queue Full! Job5 rejected
Queue Empty!

Analysis

FIFO: first job in = first job out. In a linear queue, slots before 'front' are never reused, so space is wasted (fix: circular queue).

Experiment 5

Aim

Implement Singly Linked List operations.

Part A (Question)

Create a Java program to maintain a list of student admission records using a singly linked list. Implement insertion at the beginning, at the end and at a given position, deletion of a node, searching for a record, and traversal.

Part B (Output / Analysis)

Display the list contents before and after each operation and compare the linked list implementation with an array implementation.

Java Code 

public class Exp5 {
static class Node {
int roll; String name; Node next;
Node(int r, String n) { roll = r; name = n; }
}
static Node head;
static void addFirst(int r, String n) { Node x = new Node(r, n); x.next = head; head = x; }
static void addLast(int r, String n) {
Node x = new Node(r, n);
if (head == null) { head = x; return; }
Node t = head;
while (t.next != null) t = t.next;
t.next = x;
}
static void addAt(int p, int r, String n) {
if (p == 0) { addFirst(r, n); return; }
Node t = head;
for (int i = 0; i < p - 1 && t != null; i++) t = t.next;
if (t == null) return;
Node x = new Node(r, n);
x.next = t.next; t.next = x;
}
static void delete(int r) {
if (head == null) return;
if (head.roll == r) { head = head.next; return; }
Node t = head;
while (t.next != null && t.next.roll != r) t = t.next;
if (t.next != null) t.next = t.next.next;
}
static boolean search(int r) {
for (Node t = head; t != null; t = t.next) if (t.roll == r) return true;
return false;
}
static void show() {
for (Node t = head; t != null; t = t.next) System.out.print(t.roll + ":" + t.name + " -> ");
System.out.println("null");
}
public static void main(String[] args) {
addFirst(2, "Amit"); show();
addLast(4, "Neha"); show();
addFirst(1, "Ravi"); show();
addAt(2, 3, "Pooja"); show();
delete(2); show();
System.out.println("Search 4: " + search(4) + ", Search 9: " + search(9));
}
}

Output

2:Amit -> null
2:Amit -> 4:Neha -> null
1:Ravi -> 2:Amit -> 4:Neha -> null
1:Ravi -> 2:Amit -> 3:Pooja -> 4:Neha -> null
1:Ravi -> 3:Pooja -> 4:Neha -> null
Search 4: true, Search 9: false

Analysis

Linked list: dynamic size, O(1) insertion at head, no shifting; but no random access (O(n)) and extra memory for next pointer. Array: fixed size, O(1) access.

public class Exp6 {
static class Node {
String song; Node prev, next;
Node(String s) { song = s; }
}
static Node head, tail;
static void add(String s) {
Node x = new Node(s);
if (head == null) head = tail = x;
else { tail.next = x; x.prev = tail; tail = x; }
}
static void delete(String s) {
for (Node t = head; t != null; t = t.next)
if (t.song.equals(s)) {
if (t.prev != null) t.prev.next = t.next; else head = t.next;
if (t.next != null) t.next.prev = t.prev; else tail = t.prev;
return;
}
System.out.println(s + " not found");
}
static void show() {
System.out.print("Forward : ");
for (Node t = head; t != null; t = t.next) System.out.print(t.song + " <-> ");
System.out.print("\nBackward: ");
for (Node t = tail; t != null; t = t.prev) System.out.print(t.song + " <-> ");
System.out.println();
}
public static void main(String[] args) {
add("Song A"); add("Song B"); add("Song C"); add("Song D");
show();
delete("Song B");
System.out.println("After deleting Song B:");
show();
delete("Song Z");
}
}

Backward: Song D <-> Song C <-> Song B <-> Song A <->
After deleting Song B:
Forward : Song A <-> Song C <-> Song D <->
Backward: Song D <-> Song C <-> Song A <->
Song Z not found

Analysis

Doubly list allows backward traversal and easy deletion of a known node; cost = one extra 'prev' pointer per node.

import java.util.*;
public class Exp7 {
static class Node {
String name; Node left, right;
Node(String n) { name = n; }
}
static int height(Node r) { return r == null ? 0 : 1 + Math.max(height(r.left), height(r.right)); }
static int count(Node r) { return r == null ? 0 : 1 + count(r.left) + count(r.right); }
static int leaves(Node r) {
if (r == null) return 0;
if (r.left == null && r.right == null) return 1;
return leaves(r.left) + leaves(r.right);
}
static void levelOrder(Node r) {
Queue<Node> q = new LinkedList<>();
q.add(r);
int lvl = 0;
while (!q.isEmpty()) {
System.out.print("Level " + lvl++ + ": ");
for (int i = q.size(); i > 0; i--) {
Node t = q.remove();
System.out.print(t.name + " ");
if (t.left != null) q.add(t.left);
if (t.right != null) q.add(t.right);
}
System.out.println();
}
}
public static void main(String[] args) {
Node root = new Node("CEO");
root.left = new Node("CTO");
root.right = new Node("CFO");
root.left.left = new Node("Dev"); root.left.right = new Node("QA");
root.right.left = new Node("Accountant");
levelOrder(root);
System.out.println("Height = " + height(root));
System.out.println("Nodes = " + count(root));
System.out.println("Leaves = " + leaves(root));
}
}

Level 0: CEO
Level 1: CTO CFO
Level 2: Dev QA Accountant
Height = 3
Nodes = 6
Leaves = 3

Analysis

Each node has at most 2 children, so hierarchy (CEO > CTO/CFO > staff) maps naturally. Height = longest root-to-leaf path (in nodes).

Experiment 8

Aim

Implement Inorder traversal of a Binary Tree.

Part A (Question)

Write a Java program to perform Inorder (Left – Root – Right) traversal on a binary tree of student roll numbers using both recursive and iterative (stack-based) approaches.

Part B (Output / Analysis)

Display the traversal sequence, trace the recursive calls, and explain why inorder traversal of a Binary Search Tree gives sorted output.

Java Code 

import java.util.*;
public class Exp8 {
static class Node {
int roll; Node left, right;
Node(int r) { roll = r; }
}
static Node insert(Node r, int v) {
if (r == null) return new Node(v);
if (v < r.roll) r.left = insert(r.left, v); else r.right = insert(r.right, v);
return r;
}
static void inRec(Node r) {
if (r == null) return;
inRec(r.left);
System.out.print(r.roll + " ");
inRec(r.right);
}
static void inIter(Node r) {
Stack<Node> s = new Stack<>();
while (r != null || !s.isEmpty()) {
while (r != null) { s.push(r); r = r.left; }
r = s.pop();
System.out.print(r.roll + " ");
r = r.right;
}
}
public static void main(String[] args) {
Node root = null;
for (int v : new int[]{50, 30, 70, 20, 40, 60, 80}) root = insert(root, v);
System.out.print("Recursive Inorder: "); inRec(root);
System.out.print("\nIterative Inorder: "); inIter(root);
}
}

Output

Recursive Inorder: 20 30 40 50 60 70 80
Iterative Inorder: 20 30 40 50 60 70 80

Analysis

In a BST, left < root < right, so Left-Root-Right visits keys in ascending order. Time O(n); recursion stack O(h).

import java.util.*;
public class Exp9 {
static class Node {
String name; Node left, right;
Node(String n) { name = n; }
}
static void preRec(Node r) {
if (r == null) return;
System.out.print(r.name + " ");
preRec(r.left);
preRec(r.right);
}
static void preIter(Node r) {
Stack<Node> s = new Stack<>();
s.push(r);
while (!s.isEmpty()) {
Node t = s.pop();
System.out.print(t.name + " ");

if (t.left != null) s.push(t.left);
}
}

root.right = new Node("Music");

}
}

Recursive Preorder: C: Docs Resume Photos Music Songs
Iterative Preorder: C: Docs Resume Photos Music Songs

Analysis

Preorder is used to copy/clone a tree and to get prefix expressions (operator before operands). Time O(n).

public class Exp10 {
static class Node {
String v; Node left, right;
Node(String v) { this.v = v; }
Node(String v, Node l, Node r) { this.v = v; left = l; right = r; }
}
static int post(Node r) {
if (r == null) return 0;
int a = post(r.left), b = post(r.right);
// children first
if (r.left == null && r.right == null) {
System.out.print(r.v + " ");
return Integer.parseInt(r.v);
}
System.out.print(r.v + " ");
switch (r.v) {
case "+": return a + b;
case "-": return a - b;
case "*": return a * b;

}
}

Children must be done before parent because the parent's value depends on them (expression evaluation, folder size, tree deletion). Gives postfix expression.

import java.util.*;
public class Exp11 {
public static void main(String[] args) {
String[] st = {"A", "B", "C", "D", "E", "F"};
int[][] e = {{0,1},{0,2},{1,3},{2,3},{2,4},{3,5},{4,5}};
List<List<Integer>> g = new ArrayList<>();
for (int i = 0; i < st.length; i++) g.add(new ArrayList<>());
for (int[] x : e) { g.get(x[0]).add(x[1]); g.get(x[1]).add(x[0]); }
int[] lvl = new int[st.length];
Arrays.fill(lvl, -1);
Queue<Integer> q = new LinkedList<>();
q.add(0); lvl[0] = 0;
while (!q.isEmpty()) {
int u = q.remove();
System.out.println("Visited " + st[u] + " (level " + lvl[u] + ")");
for (int v : g.get(u))
if (lvl[v] == -1) { lvl[v] = lvl[u] + 1; q.add(v); }
}
}
}

Visited B (level 1)
Visited C (level 1)
Visited D (level 2)
Visited E (level 2)
Visited F (level 3)

Analysis

BFS visits level by level using a Queue, so the first time a node is reached is via the fewest edges (shortest path in unweighted graph). Time O(V+E).

Experiment 12

Aim

Implement Depth-First Search (DFS) on a graph using an adjacency list.

Part A (Question)

Write a Java program to represent a social network as a graph using an adjacency list and perform DFS (recursive and stack-based) to find all users connected to a given user.

Part B (Output / Analysis)

Display the DFS traversal order, compare it with the BFS order of the same graph, and explain the behavior of DFS in deep exploration.

Java Code 

import java.util.*;
public class Exp12 {
static List<List<Integer>> g = new ArrayList<>();
static String[] u = {"Ann", "Bob", "Cat", "Dan", "Eve", "Fay"};
static void dfs(int x, boolean[] vis) {
vis[x] = true;
System.out.print(u[x] + " ");
for (int v : g.get(x)) if (!vis[v]) dfs(v, vis);
}
static void dfsStack(int s) {
boolean[] vis = new boolean[u.length];
Stack<Integer> st = new Stack<>();
st.push(s);
while (!st.isEmpty()) {
int x = st.pop();
if (vis[x]) continue;
vis[x] = true;
System.out.print(u[x] + " ");
List<Integer> l = g.get(x);
for (int i = l.size() - 1; i >= 0; i--) if (!vis[l.get(i)]) st.push(l.get(i));
}
}
public static void main(String[] args) {
for (int i = 0; i < u.length; i++) g.add(new ArrayList<>());
int[][] e = {{0,1},{0,2},{1,3},{2,3},{4,5}}; // Eve-Fay not connected to Ann
for (int[] x : e) { g.get(x[0]).add(x[1]); g.get(x[1]).add(x[0]); }
System.out.print("DFS recursive from Ann: "); dfs(0, new boolean[u.length]);
System.out.print("\nDFS stack-based from Ann: "); dfsStack(0);
}
}

Output

DFS recursive from Ann: Ann Bob Dan Cat
DFS stack-based from Ann: Ann Bob Dan Cat

Analysis

DFS goes as deep as possible before backtracking (uses recursion/stack); BFS goes level by level. Time O(V+E).

import java.util.*;
public class Exp13 {
public static void main(String[] args) {
int[] a = {64, 25, 12, 22, 11};
int cmp = 0, swp = 0;
for (int i = 0; i < a.length - 1; i++) {
int min = i;
for (int j = i + 1; j < a.length; j++) {
cmp++;
if (a[j] < a[min]) min = j;
}
if (min != i) {
int t = a[i]; a[i] = a[min]; a[min] = t; swp++;
System.out.println("Pass " + (i + 1) + " (swap " + a[min] + "," + a[i] + "): " + Arrays.toString(a));
} else System.out.println("Pass " + (i + 1) + " (no swap): " + Arrays.toString(a));
}
System.out.println("Sorted: " + Arrays.toString(a));
System.out.println("Comparisons = " + cmp + ", Swaps = " + swp);
}
}

Output

Pass 1 (swap 64,11): [11, 25, 12, 22, 64]
Pass 2 (swap 25,12): [11, 12, 25, 22, 64]
Pass 3 (swap 25,22): [11, 12, 22, 25, 64]
Pass 4 (no swap): [11, 12, 22, 25, 64]
Sorted: [11, 12, 22, 25, 64]
Comparisons = 10, Swaps = 3

Analysis

Time: Best/Average/Worst = O(n^2) (always n(n-1)/2 comparisons). Swaps at most n-1. Not stable, in-place.

import java.util.*;
public class Exp14 {
static int sort(int[] a, boolean print) {
int shifts = 0;
for (int i = 1; i < a.length; i++) {
int key = a[i], j = i - 1;
while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; shifts++; }
a[j + 1] = key;
if (print) System.out.println("Insert " + key + ": " + Arrays.toString(a));
}
return shifts;
}

System.out.println("Shifts (sorted) : " + sort(new int[]{1, 2, 3, 4, 5}, false));
System.out.println("Shifts (reverse) : " + sort(new int[]{5, 4, 3, 2, 1}, false));
System.out.println("Shifts (random) : " + sort(new int[]{3, 1, 5, 2, 4}, false));
}
}

import java.util.*;
public class Exp16 {
static int partition(int[] a, int lo, int hi, boolean print) {
int p = a[hi], i = lo - 1;
// last element as pivot
for (int j = lo; j < hi; j++)
if (a[j] < p) { i++; int t = a[i]; a[i] = a[j]; a[j] = t; }
int t = a[i + 1]; a[i + 1] = a[hi]; a[hi] = t;
if (print) System.out.println("Pivot " + p + ": " + Arrays.toString(a));
return i + 1;
}
static void quick(int[] a, int lo, int hi, boolean print) {
if (lo < hi) {
int p = partition(a, lo, hi, print);
quick(a, lo, p - 1, print);
quick(a, p + 1, hi, print);
}
}
public static void main(String[] args) {
int[] d = {10, 7, 8, 9, 1, 5};
quick(d, 0, d.length - 1, true);
System.out.println("Sorted: " + Arrays.toString(d));
Random r = new Random();
for (int n : new int[]{1000, 10000, 100000, 1000000}) {
int[] a = r.ints(n, 0, 1000000).toArray();
long s = System.nanoTime();
quick(a, 0, n - 1, false);
System.out.println("n = " + n + " -> " + (System.nanoTime() - s) / 1000 + " microseconds");
}
}
}
